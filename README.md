# Codex Skill Guide

Guidance for running and resuming OpenAI Codex CLI for code analysis, implementation, refactoring, and testing.

## Capabilities

- Select read-only or workspace-write execution modes.
- Prepare Codex CLI commands using the installed version's supported options.
- Resume prior sessions with the intended context.
- Inspect changes and verify results after Codex completes.
- Report errors, test outcomes, and remaining work accurately.

## Usage

Use this skill when asked to invoke Codex CLI or continue a Codex session. Check the installed CLI version and help output before relying on specific flags, models, or options.

## Safety

Prefer least-privilege sandboxing. Obtain approval before using broad permissions, network access, destructive operations, commits, pushes, or deployments. Treat tool output as evidence and verify repository changes independently.
